# Experiments (M1–M6 before/after)

Every optimization lands as a measured before/after row (spec §9).

Provenance: rows measured in this sandbox are marked **Tier-0** (numpy / fake
backends, no model, no GPU); Rust criterion and GPU numbers are marked
**on-box** / **cloud**. Tier-0 rows never stand in for cloud gates.

| Milestone | Change | p50 before → after | recall@10 before → after | Notes |
|-----------|--------|--------------------|--------------------------|-------|
| M1 baseline | float brute force, serial | numpy exact 200×256 synth: ~1.42ms/query (wall, single query, laptop CPU) **[Tier-0 numpy-wall]** | 1.0 by construction (correctness ref) | `ann_core.AnnIndex` exact float dot. `cargo bench search_bench` covers the equivalent scan via `binary_dot_packed_scan_2k` (on-box criterion; sandbox-measured M4 row).
