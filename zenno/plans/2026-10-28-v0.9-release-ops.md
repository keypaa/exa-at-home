# v0.9 Release Operations — exhaustive ordered plan

## North star
One GPU + limited network gives an agent a **single-sub-100-ms text indexer/searcher** that
is easy to install, does not lie about its measured results, and survives a real box wipe.

**Fields pinned by the 1 M (2026-10-25) artifact:** n_docs=2,576,778, K=10,000,
p50=75.562, p99=131.151, G1=0.359 vs 0.2885 (drop −0.0705), G3 budget 100 ms.

## Ordered rule set (never invert steps 1–3)

1. **Measurement pin** — every artifact landed in a GitHub commit, no floating refs.
2. **Self-contained service** — one command to build, one to serve, `--help` works offline.
3. **Tier-0 + Tier-2 gates** — 4 gates, lane B/LaneC exit 0; GitHub Actions runs synth nightly.
4. **Audit pass** — every P0/P1 item turned into a PR, the first two "before-merge" gates.
5. **Model levers** (max_seq_length, ingest disk dedup, CPU-only path) — measured
   **A-B only on real data, never rebranded as the same case**.
